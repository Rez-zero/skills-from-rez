# 合同比对 Skill

## 触发场景
- "比对合同" / "对比文档" / "找出差异"
- 上传两份文件要求对比差异
- "这份和那份有什么不同"

## 工作流

1. **确认两份文件**
   - 先确认基准文件（称"原文件"）
   - 再确认比对文件（称"待标文件"）
   - 支持格式：.doc / .docx / .pdf

2. **执行比对脚本**
   ```
   python scripts/compare_docs.py <原文件路径> <待标文件路径> <输出目录>
   ```

3. **返回结果**
   - .docx 待标文件 → 生成带批注的新 .docx
   - .pdf 待标文件 → 生成带高亮的新 .pdf
   - 结果文件默认放在输入文件同级目录，文件名加 `_compared` 后缀

## 输出说明

### .docx 批注格式
- 每个差异处新增一条批注
- 批注内容：`[差异] 原文件内容 → 比对文件内容`
- 删除内容标为红色底纹 + 删除线
- 新增内容标为蓝色底纹
- 修改内容标为黄色底纹

### .pdf 高亮格式
- 删除内容：红色高亮
- 新增内容：蓝色高亮
- 修改内容：黄色高亮
- 点击高亮处可查看详情

## 支持格式说明
- `.doc` 文件会先转换为 `.docx` 再处理
- 如果原文件和待标文件格式不同，先转为统一格式再比对
- 大文件处理可能需要几秒，请稍候

## 依赖安装

首次使用需要安装依赖：
```bash
pip install python-docx pymupdf python-docx lxml
```

## 注意事项
- 脚本在当前工作目录执行，路径不要有中文
- 如果文件较大，比对可能需要较长时间
