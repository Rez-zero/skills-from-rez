# 合同比对 Skill - 使用说明

## 安装依赖

首次使用前需要安装 Python 依赖：

```bash
pip install python-docx pymupdf
```

## 使用方法

### 触发 Skill

向 Claude 说"比对合同"或"对比文档"，然后按提示操作。

### 第一步：提供原文件

上传或告诉 Claude 原文件路径。这是基准文件，所有差异都相对于它。

### 第二步：提供待标文件

上传或告诉 Claude 需要标注差异的文件路径。

### 第三步：获取结果

Claude 调用脚本处理后，会返回带标注的新文件：
- `.docx` 文件：带批注（删除线/高亮）
- `.pdf` 文件：带彩色高亮

## 支持格式

| 格式 | 处理方式 |
|------|----------|
| `.docx` | 直接添加批注 |
| `.doc` | 先转 `.docx`，再添加批注 |
| `.pdf` | 添加高亮标注 |

## 标注说明

### .docx 批注
- **删除内容**：红色删除线 + 灰色底纹
- **新增内容**：蓝色底纹
- **修改内容**：黄色底纹 + 批注说明

### .pdf 高亮
- **删除内容**：红色高亮
- **新增内容**：蓝色高亮
- **修改内容**：黄色高亮

点击高亮区域可查看详情。

## 示例对话

```
用户: 比对合同
Claude: 请提供原文件（作为基准的文件）
用户: [上传 contract_v1.docx]
Claude: 已收到原文件，现在请提供需要比对的文件
用户: [上传 contract_v2.docx]
Claude: 正在比对两份合同...
       发现 5 处差异
       [下载链接: contract_v2_compared.docx]
```

## 注意事项

1. 路径不要包含中文，否则可能无法读取
2. 大文件处理可能需要十几秒
3. 如果两份文件格式不同（如原文件是 pdf，待标文件是 docx），会先统一格式再比对
4. `.doc` 文件转换需要本地安装 Microsoft Word
