# 合同脱敏 Skill

## 触发场景
- "脱敏合同"
- "合同脱敏"
- "隐藏合同信息"
- "加密合同"
- "匿名化合同"

## 支持格式
- `.doc` / `.docx` / `.pdf` / `.txt`

## 工作流

1. **用户提供合同文件**
   - 上传文件 或 提供文件路径
   - Claude 自动识别文件格式

2. **识别敏感信息**
   - 读取合同全文
   - 识别所有当事方（企业全称 + 简称）
   - 识别联系方式、地址、账号等

3. **执行脱敏**
   - 用户选择脱敏方式
   - Claude 批量处理

4. **保存结果**
   - 输出脱敏后的文件（同格式）
   - 文件名加 `_sanitized` 后缀

## 脱敏方式

| 方式 | 说明 | 示例 |
|------|------|------|
| 黑条遮挡 | ███ 保持长度 | 张三 → ██ |
| 直接消除 | 删除内容 | 张三 → [姓名] |
| 代称替换 | 甲方/乙方代称 | 张三 → \<甲方\> |

## 必须脱敏的内容

### 当事方信息（重点）
- 企业全称（如"浙江核新同花顺网络服务股份有限公司"）
- 企业简称（如"同花顺"）
- **全称和简称都要脱敏**

### 联系信息
- 电话号码、手机号
- 电子邮箱
- 地址（注册地址、经营地址）

### 企业信息
- 统一社会信用代码
- 法定代表人
- 开户银行、银行账号

### 注意
- "甲方"、"乙方"等代称本身不变
- 脱敏的是代称指向的**具体企业名称**
- 简称识别：合同先出现的全称，之后出现的简称也要脱敏

