# 中国法律背景 NDA Skill 使用说明

## 功能介绍

`nda-triage-prc` 是一份面向中国大陆商业与法律语境的 NDA 初筛 skill，用于快速审查保密协议、保密条款或类似文件，并按风险分为：

- `GREEN`：标准可通过。
- `YELLOW`：需要法务审阅，通常可通过定向修改解决。
- `RED`：存在重大风险，需要完整法务审查或升级处理。

它重点关注中国大陆实务中常见问题，包括保密信息定义、标准例外、商业秘密保护、违约金、适用法律与争议解决、员工不招揽、竞业限制、排他条款、知识产权、个人信息和数据合规等。

## 适用场景

适合在以下情况下使用：

- 业务部门收到对方 NDA，需要判断能否进入签署流程。
- 需要快速识别 NDA 中的黄色或红色风险点。
- 需要把复杂法律问题转化为业务可理解的问题清单。
- 需要给出修改方向、流转建议或是否使用我方标准 NDA 的建议。
- 需要审查中国法、中国主体、中国业务合作或涉及中国数据合规的保密文件。

不适合替代正式法律意见。对外发送红线版本、签署协议或确认法律立场前，应由有资质的法律专业人员复核。

## 使用方法

在 Cursor 对话中可以直接提出类似请求：

```text
请使用 nda-triage-prc 审查这份 NDA，并按 GREEN/YELLOW/RED 分级。
```

也可以提供更具体的背景：

```text
我方是接收方，场景是技术评估，对方要求中国公司签署。请按中国法律背景审查这份 NDA，列出主要风险和修改建议。
```

如果 NDA 内容较长，建议同时提供：

- 我方角色：披露方、接收方或双方均披露。
- 交易场景：采购、销售、技术合作、投融资、M&A、数据共享等。
- 是否涉及个人信息、源代码、算法、客户名单、价格或其他敏感信息。
- 是否必须接受对方模板，或可以发送我方标准 NDA。
- 期望输出：只要结论、风险清单、红线建议、流转建议或完整审查摘要。

## 支持输入

- 直接粘贴 NDA、保密协议或保密条款文本。
- 提供文件路径，例如 `.txt`、`.md`、`.pdf`、`.docx`。
- 提供合同中的保密条款摘录。
- 提供业务背景并要求判断是否可以签署。

如 PDF 或 Word 文件无法可靠读取，建议提供 OCR/导出的 `.txt` 文本或直接粘贴关键条款。

## 可选输出

- **只给结论**：仅输出分级、核心理由和下一步建议。
- **风险清单**：重点列出 YELLOW / RED 问题。
- **修改建议**：逐条给出建议修改方向或谈判立场。
- **业务版摘要**：用业务人员能理解的语言说明风险和处理建议。
- **完整审查摘要**：按默认格式输出分级、主要问题、建议修改、流转建议和待确认信息。

## 兜底处理

如果没有提供文件或文本，skill 会要求用户上传或粘贴 NDA 内容；如果 PDF/Word 无法可靠读取，会要求提供 OCR 或 `.txt` 文本；如果文件并非 NDA 或混入大量采购、投资、劳动、IP、数据处理等实质条款，会只做保密部分初筛，并提示转交对应合同审查。

如果我方角色不明、内容只是条款摘录或信息不足，skill 不会直接给 GREEN，而会标记为初步结果并列出待确认信息。

## 默认输出

skill 默认使用以下结构：

```markdown
## 分级
[GREEN / YELLOW / RED] - [一句话说明核心原因]

## 主要问题
- [问题 1]
- [问题 2]

## 建议修改
- [修改建议或谈判立场]

## 流转建议
[标准通过 / 法务审阅 / 完整法务审查 / 升级资深法务 / 发送我方模板 / 暂不签署]

## 待确认信息
- [信息不足时列出需要补充的问题]
```

## 文件位置

本版本为独立中国法语境版本，位置为：

```text
nda-skill-china/SKILL.md
```
